🔒 SEGURANÇA & ARQUITETURA Este painel opera 100% no navegador (Client-Side) com persistência em LocalStorage. Nenhuma chave secreta ou credencial de pagamento é exposta no código frontend. Todos os checkouts utilizam redirecionamento externo para gateways seguros certificados (ex: Hotmart).

Exportação, Importação e Persistência de Dados

Toda a configuração deste motor estático é armazenada no LocalStorage do seu navegador de forma autônoma e segura, sem depender de banco de dados centralizado. Você pode exportar backups completos em arquivo JSON para versionamento, migração ou publicação direta no GitHub Pages.

📦 Exportar Backup Completo

Baixe um arquivo JSON com todos os produtos, fluxos, configurações e ofertas modificadas.

📤 Importar Configuração JSON

Carregue um arquivo JSON de backup ou de produto exportado previamente. O sistema valida os nós e ofertas automaticamente antes de aplicar.

⚠️ Restaurar Configurações Originais

Apaga os rascunhos e customizações do LocalStorage, restaurando os arquivos estáticos originais de cada produto.
